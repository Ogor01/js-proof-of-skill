# Reverse a String Function

## What it does
Enter any word or sentence and it returns the text reversed.
Built manually with a loop to understand how string reversal works internally.

## What I learned
- Looping through a string backwards
- Building a new string character by character
- Why split reverse join is the shortcut version
- Separating pure logic from DOM handling

## How to run
Open index.html in your browser.


**Test it with these values:**
- `hello` → `olleh`
- `Charles` → `selrahC`
- `racecar` → `racecar` (palindrome — same forwards and backwards)
- `Hello World` → `dlroW olleH`
- empty → Please enter some text
