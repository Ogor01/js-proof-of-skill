# Interest Calculator

## What it does
Calculates both simple and compound interest.
Switch between modes using the tabs at the top.
Shows the interest earned and total amount.

## What I learned
- Simple interest formula: (P × R × T) / 100
- Compound interest formula: P × (1 + R/100)^T
- Using Math.pow() for exponents
- Tab switching with classList.add and classList.remove
- Storing UI state in a variable

## How to run
Open index.html in your browser.

**Test it with these values:**
- Principal $1000, Rate 5%, Time 3 years
- Simple → Interest $150.00 | Total $1150.00
- Compound → Interest $157.63 | Total $1157.63
- Any empty field → Please fill in all fields
- Any value at 0 → All values must be greater than 0
