# BMI Calculator

## What it does
Calculates Body Mass Index in both metric and imperial units.
Shows BMI value and category — Underweight, Normal, Overweight or Obese.

## What I learned
- BMI formula for metric and imperial units
- Switching placeholder text dynamically based on selected unit
- Returning objects from functions to carry multiple values
- Separating calculation logic from category logic

## How to run
Open index.html in your browser.

**Test it with these values:**
- 70kg, 175cm → BMI 22.9 — Normal weight
- 50kg, 175cm → BMI 16.3 — Underweight
- 90kg, 175cm → BMI 29.4 — Overweight
- 120kg, 175cm → BMI 39.2 — Obese
- Imperial: 154lbs, 69in → BMI 22.7 — Normal weigh
