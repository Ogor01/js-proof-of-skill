# Reusable Calculator Functions

## What it does
A calculator with four operations — add, subtract, multiply and divide.
Each operation is its own reusable function that can be called anywhere.

## What I learned
- Writing small reusable functions with single responsibilities
- Passing functions as arguments to other functions
- Handling divide by zero edge case
- Using a shared handleCalculation function to avoid repetition

## How to run
Open index.html in your browser.

**Test it with these values:**
- 10 + 5 → 15.00
- 10 - 3 → 7.00
- 4 × 6 → 24.00
- 10 ÷ 2 → 5.00
- 10 ÷ 0 → Cannot divide by zero
- empty inputs → Please enter both numbers
