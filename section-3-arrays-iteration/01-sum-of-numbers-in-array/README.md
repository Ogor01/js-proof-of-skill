# Sum of Numbers in an Array

## What it does
Enter numbers separated by commas and it calculates the total sum.
Built manually with a loop before using the reduce shortcut.

## What I learned
- Parsing a comma separated string into an array of numbers
- Using split() and map() together to transform input
- Building a sum manually with a for loop
- Validating array values with some()

## How to run
Open index.html in your browser.

**Test it with these values:**
- `1, 2, 3, 4, 5` → Sum: 15
- `10, 20, 30` → Sum: 60
- `-5, 10, -3` → Sum: 2
- `1.5, 2.5, 3` → Sum: 7
- `1, abc, 3` → Please enter valid numbers
- empty → Please enter some numbers
