# Merge Two Arrays

## What it does
Enter two comma separated arrays and merge them together.
Option to merge with or without duplicates using two buttons.

## What I learned
- Manually merging arrays with loops before using concat and spread
- Using Set to remove duplicates after merging
- The difference between concat() and spread for merging
- Combining two previously learned concepts — merging and deduplication

## How to run
Open index.html in your browser.


**Test it with these values:**
- `1, 2, 3` and `4, 5, 6` merge → 1, 2, 3, 4, 5, 6
- `1, 2, 3` and `3, 4, 5` merge → 1, 2, 3, 3, 4, 5
- `1, 2, 3` and `3, 4, 5` merge unique → 1, 2, 3, 4, 5
- `apple, banana` and `banana, orange` merge unique → apple, banana, orange
- empty field → Please fill in both arrays
