# Remove Duplicates from an Array

## What it does
Enter values separated by commas and it removes all duplicate values.
Shows the original list, unique list and how many duplicates were removed.
Works with both numbers and words.

## What I learned
- Building a manual duplicate checker with a seen array
- Why Set is the modern shortcut for removing duplicates
- Counting removed duplicates by comparing lengths
- Filtering works on strings not just numbers

## How to run
Open index.html in your browser.


**Test it with these values:**
- `1, 2, 2, 3, 3, 4` → Removed 2 duplicates
- `apple, banana, apple, orange, banana` → Removed 2 duplicates
- `1, 2, 3, 4, 5` → Removed 0 duplicates
- `5, 5, 5, 5` → Removed 3 duplicates
- empty → Please enter some values
