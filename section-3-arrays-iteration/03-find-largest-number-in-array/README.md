# Find Largest Number in an Array

## What it does
Enter numbers separated by commas and it finds the largest value.
Built manually with a loop before using Math.max shortcut.

## What I learned
- Manual comparison loop to find the largest value
- Why you start with numbers[0] as the assumed largest
- Math.max with spread operator as the shortcut
- Reusing the comma separated input parsing pattern

## How to run
Open index.html in your browser.


**Test it with these values:**
- `3, 7, 1, 9, 4` → Largest: 9
- `-5, -1, -8, -2` → Largest: -1
- `100` → Largest: 100
- `5, 5, 5` → Largest: 5
- `1, abc, 3` → Please enter valid numbers
- empty → Please enter some numbers
