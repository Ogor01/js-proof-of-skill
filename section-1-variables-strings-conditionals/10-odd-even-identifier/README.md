# Odd and Even Number Identifier

## What it does
Enter any number and it tells you whether it is odd or even.
Also handles the special case of zero.

## What I learned
- The modulo operator % and how it works
- Why 0 is a special case worth handling
- Simple conditional logic with one operator

## How to run
Open index.html in your browser.


**Test it with these values:**
- `4` → Even
- `7` → Odd
- `0` → neither odd nor even
- `-3` → Odd
- `-8` → Even
- empty → Please enter a valid number
