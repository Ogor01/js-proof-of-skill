# Greeting Message Generator

## What it does
Enter your name and get a greeting based on the current time of day.
Morning, Afternoon, Evening or Night — it detects automatically.

## What I learned
- Using the Date object to get the current hour
- Time based conditional logic
- Template literals with dynamic values

## How to run
Open index.html in your browser.


**Test it:**
- Type your name and click — it should greet you based on whatever time it is right now on your computer
