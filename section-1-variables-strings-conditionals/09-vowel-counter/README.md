# Vowel Counter

## What it does
Enter any word or sentence and it counts how many vowels are in it.
Handles both uppercase and lowercase vowels.

## What I learned
- Looping through a string character by character
- Using includes() to check if a character exists in a string
- Singular vs plural grammar in output using ternary operator

## How to run
Open index.html in your browser.

**Test it with these values:**
- `hello` → 2 vowels
- `rhythm` → 0 vowels
- `a` → 1 vowel
- `Hello World` → 3 vowels
- empty → Please enter some text
