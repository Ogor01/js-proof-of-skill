# Simple Discount Calculator

## What it does
Enter an original price and a discount percentage.
It calculates how much you save and what the final price is.

## What I learned
- Working with two inputs at the same time
- Percentage calculation formula
- Multiple input validations
- toFixed() for currency formatting

## How to run
Open index.html in your browser.



**Test it with these values:**
- $100 with 20% off → Saved $20.00 | Final $80.00
- $250 with 50% off → Saved $125.00 | Final $125.00
- negative price → Price must be greater than 0
- discount of 150 → Discount must be between 0 and 100
- empty inputs → Please enter both price and discount
