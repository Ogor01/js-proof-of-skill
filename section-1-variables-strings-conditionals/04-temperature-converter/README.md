# Temperature Converter

## What it does

Converts temperatures between Celsius, Fahrenheit and Kelvin.
Select your from unit, to unit, enter a value and click Convert.

## What I learned

- Working with dropdown select elements in HTML
- parseFloat for decimal numbers
- Temperature conversion formulas
- Handling same unit edge case

## How to run

Open index.html in your browser.

**Test it with these values:**

- 100 Celsius → Fahrenheit = 212.00
- 32 Fahrenheit → Celsius = 0.00
- 0 Celsius → Kelvin = 273.15
- Same unit selected → should say "same unit, no conversion needed"
