# Basic Grade Calculator

## What it does
Enter a score between 0 and 100 and get your letter grade.
A = 90-100, B = 80-89, C = 70-79, D = 60-69, F = below 60

## What I learned
- if/else if/else conditionals with number ranges
- Input validation for out of range values
- Separating display logic into a helper function

## How to run
Open index.html in your browser.


**Test it with these values:**
- 95 → A — Excellent!
- 85 → B — Good Job!
- 75 → C — Average
- 65 → D — Below Average
- 45 → F — Failed
- 150 → Score must be between 0 and 100
- empty → Please enter a valid score
